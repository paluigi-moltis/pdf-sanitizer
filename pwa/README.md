# pwa/ — Milestone 3: offline-first PWA

Offline-capable Progressive Web App (Vite + TypeScript + Tailwind v4 +
Workbox). All PDF processing runs **locally in a Web Worker** through the
WASM engine (`crates/wasm`): rasterization (hayro), OCR (ocrs/rten) and the
dual-path rule engine never leave the browser.

## Features

- Drag-and-drop (or file picker) PDF upload — bytes never leave the device
- Split-pane report view:
  - **Left**: rendered page canvases with color-coded `bbox_norm` overlay
    boxes per finding (critical/red → low/blue)
  - **Right**: risk-level banner + counts, clickable finding cards
    (severity, page, surface, reason, expandable quarantined snippet);
    clicking a card scrolls to and flashes the exact overlay on the page
  - **Sanitized Markdown tab** with one-click Copy and `.md` /
    `.report.json` downloads
- Built-in **Hostile demo** / **Benign demo** buttons (synthetic PDFs
  generated by the WASM engine itself — try it without any file)
- Page-by-page progress bar (worker → UI messages)
- Full offline: Workbox service worker precaches the app, the `.wasm`
  engine and the OCR model files (IndexedDB fallback in the worker)

## Development

```console
$ scripts/download-models.sh tests/fixtures/models   # one-time OCR models
$ cd pwa
$ npm install
$ npm run build:wasm      # wasm-pack + stage models into public/models
$ npm run dev             # dev server
$ npm run build           # tsc + vite build (generates service worker)
$ npm run preview         # serve the production build
```

## Architecture

```
main.ts            UI thread: drop zone, split-pane report, overlays, tabs
worker.ts          Web Worker: loads wasm + models (Cache Storage/IndexedDB),
                   runs SanitizerWasm, posts progress + results (transferred
                   RGBA buffers)
src/wasm/          wasm-pack output (gitignored; built by build:wasm)
public/models/     OCR models staged from tests/fixtures (gitignored)
```
